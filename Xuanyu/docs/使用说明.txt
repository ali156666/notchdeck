悬屿 使用说明
=============

官网地址：https://notchdeck.xyz/
API 推荐：https://shop.xuedingtoken.com/?dist=KDLDYHBS


一、安装

1. 打开「NotchDeck-1.0.28.dmg」。
2. 将「悬屿.app」拖到「Applications」文件夹。
3. 从「应用程序」里启动「悬屿」。

悬屿是顶栏常驻应用，不会出现在 Dock 里。启动后看 MacBook 顶部刘海区域或屏幕顶部中央。


二、首次使用

1. 点击顶部悬屿区域展开面板。
2. 音乐页会读取 Apple Music 或 Spotify 的播放状态。
3. 系统看板会按需请求位置、日历等权限。
4. Agent 功能需要在悬屿设置里填写模型地址和 API key。
5. 长按左或右 Command 0.5 秒开始语音输入，保持按住说话，松开后先审核识别内容，确认后发送给 Agent。
6. 语音设置可选择 Apple 识别，或下载本地 SenseVoice 模型离线识别。
7. 短按 Command、⌘C、⌘V、⌘Tab 等组合键不会触发录音。
8. Agent 默认启用「工作区可写」沙箱，工作区为 ~/XuanyuWorkspace；可在 Agent 设置 -> 沙箱中修改。

配置文件保存在：

~/Library/Application Support/Xuanyu/agent/config.json

Agent 默认工作区：

~/XuanyuWorkspace

沙箱默认允许读取本机文件，只允许写入工作区和临时目录，并禁止子进程联网；.git、.agents、.codex 始终受保护。需要下载依赖时，可在沙箱设置中单独开启联网。


三、需要授权的系统权限

- 自动化 / Apple Events：读取和控制 Apple Music、Spotify。
- 蓝牙：读取 AirPods 连接状态和电量。
- 位置：显示天气。
- 日历：显示近期日程。
- 输入监控：监听长按 Command，不会拦截普通快捷键。
- 麦克风：采集语音输入。
- 语音识别：仅 Apple 识别后端需要；本地 SenseVoice 不需要。
- 网络：请求歌词、天气和模型接口。

如果音乐状态显示「需要授权」，请打开：

系统设置 -> 隐私与安全性 -> 自动化

然后允许「悬屿」控制 Apple Music 或 Spotify。


四、打不开的应对办法

情况 A：提示「无法打开，因为无法验证开发者」

1. 在「应用程序」里找到「悬屿.app」。
2. 按住 Control 键点「悬屿.app」，选择「打开」。
3. 在弹窗里再次点击「打开」。

也可以打开：

系统设置 -> 隐私与安全性

在页面底部找到关于「悬屿」的拦截提示，点击「仍要打开」。


情况 B：提示「悬屿.app 已损坏，无法打开」

打开「终端」，执行：

xattr -dr com.apple.quarantine /Applications/悬屿.app

然后重新打开「悬屿.app」。


情况 C：点击后没有反应

1. 确认旧版本已经退出。
2. 打开「活动监视器」，搜索「悬屿」或「Xuanyu」，结束旧进程。
3. 重新从「应用程序」启动。

也可以在终端执行：

pkill -x Xuanyu
open -a 悬屿


情况 D：音乐连接不上

1. 确认 Apple Music 或 Spotify 已经打开，并且正在播放或有当前曲目。
2. 打开系统设置：

系统设置 -> 隐私与安全性 -> 自动化

3. 允许「悬屿」控制 Apple Music 或 Spotify。
4. 如果之前拒绝过权限，可以在终端执行：

tccutil reset AppleEvents com.xuanyu.app

然后重新打开悬屿，并在弹窗里点击「允许」。


情况 E：长按 Command 没有进入语音输入

1. 打开系统设置：

系统设置 -> 隐私与安全性 -> 输入监控

2. 允许「悬屿」监听键盘输入。
3. 打开系统设置：

系统设置 -> 隐私与安全性 -> 麦克风

4. 允许「悬屿」使用麦克风。
5. 如果使用 Apple 识别后端，还需要在「语音识别」里允许「悬屿」。
6. 如果使用本地 SenseVoice 后端，请先在 Agent 设置里下载模型；模型约 239.5 MB。


五、退出应用

展开悬屿面板后，点击右上角电源按钮，确认后退出。
